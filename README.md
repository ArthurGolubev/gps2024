# GPS 2024

## Описание проекта

`gps2024` – небольшое утилитарное приложение на Python, которое собирает данные с публичного сайта **toplist.run** о соревнованиях по горным походам за сутки в 2024 году, сохраняет их в JSON и визуализирует с помощью **Plotly**. В проекте реализованы два основных класса:

* `Competition` – основной API, выполняющий скачивание протоколов соревнований по заданному id
* `ProtocolSchema` – валидируемые данные о протоколе, описанные через **Pydantic**


## Требования

* Python 3.10+ (используется `pyproject.toml`)
* Poetry для управления зависимостями

## Установка

```bash
# Клонируйте репозиторий
git clone https://github.com/ваш-аккаунт/gps2024.git
cd gps2024

# Установите зависимости (создаст виртуальное окружение)
poetry install
```

## Запуск

После установки можно сразу запустить скрипт, который скачает протоколы и построит графики:

```bash
poetry run python -m main
```

Пример для конкретного соревнования (см. директорию `gornyi-pokhod-za-sutki-2024`):

```bash
poetry run python -m main
```

> Скрипт `main.py` реализует **CLI** через прямое выполнение в секции `if __name__ == '__main__'`. Для более гибкого использования можно импортировать `Competition` и вызывать методы из собственного скрипта.
